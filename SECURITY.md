# Security Policy

## Reporting a problem in this toolkit

If you find a security issue *in this project itself*, report it privately and
don't open a public issue. Examples: the script doing something unsafe, a CI
workflow that leaks a token, or guidance that would leave apps vulnerable.

- Use GitHub's **"Report a vulnerability"** button (Security tab → Advisories), or
- Go directly to [github.com/parag0508-lang/shipready/security/advisories/new](https://github.com/parag0508-lang/shipready/security/advisories/new).

We aim to acknowledge reports within 3 days.

## Out of scope

This project doesn't accept reports about vulnerabilities in third-party
software. Report those to that vendor or project directly.
